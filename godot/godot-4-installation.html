Godot 4 安装教程（Windows 2026最新版）｜下载、安装、创建第一个项目（完整指南） ​

本教程适用于搜索以下问题的用户：

  • Godot 4 安装教程
  • Godot 4 Windows 下载
  • 如何安装 Godot 引擎
  • Godot 4 创建第一个项目

Godot 是一款免费、开源、跨平台的游戏引擎，适合独立开发者、初学者和小团队使用。
本文将以 Windows 为例，带你完成 Godot 4 下载、安装、首次启动和创建第一个项目。

官网地址：https://godotengine.org/zh-cn/

一、下载 Godot 4 ​

Godot 可以从多个渠道下载，建议优先使用官方渠道。

1. 官方下载页 ​

  • Windows 下载页：https://godotengine.org/download/windows/
  • 官方镜像页：https://godotengine.itch.io/godot

2. 下载哪个版本 ​

一般情况下，Windows 用户直接下载带有以下后缀的版本即可：

  • x86_64
  • 64-bit

如果你只想用 GDScript 开发，直接下载标准版即可。
如果你需要 C# 支持，可以选择对应的 C# 版本。

提示：如果网络环境限制导致下载不方便，可以通过社区或交流群获取帮助。

二、安装 Godot ​

Godot 的安装方式非常简单，它通常不需要传统意义上的“安装程序”。

1. 解压下载包 ​

下载完成后，你会得到一个压缩包。
解压后，通常会看到两个可执行文件：

  • Godot_v4.x.x-stable_win64.exe
  • Godot_v4.x.x-stable_win64_console.exe

2. 启动 Godot ​

一般情况下，直接双击主程序即可：

  • Godot_v4.x.x-stable_win64.exe

如果你需要查看命令行输出、调试信息或报错信息，可以运行：

  • Godot_v4.x.x-stable_win64_console.exe

三、第一次启动 Godot ​

首次启动后，你会看到 Godot 的项目管理器界面。
如果系统语言设置正常，界面通常会自动显示为中文。

1. 建议使用中文目录 ​

创建项目时，建议尽量把项目放在 中文路径较少、英文路径清晰 的目录下。
这样可以减少某些路径识别问题，尤其是在导出、插件或第三方工具配合使用时更稳妥。

2. 认识项目管理器 ​

你会在这里看到：

  • 新建项目
  • 导入项目
  • 最近打开的项目

对于新手来说，通常从 新建项目 开始即可。

四、创建第一个项目 ​

1. 点击“新建项目” ​

在项目管理器中点击 新建项目。

2. 填写项目信息 ​

你需要设置：

  • 项目名称：例如 MyFirstGame
  • 项目路径：建议选择一个干净的英文目录
  • 渲染器：新手通常保持默认即可

3. 创建项目 ​

确认无误后，点击创建。
Godot 会自动生成项目文件，并打开编辑器。

五、创建第一个场景 ​

Godot 的开发方式非常核心的一点，就是 先做场景，再做游戏逻辑。

1. 新建场景 ​

在目录中右键

2. 添加根节点 ​

一般可以从以下节点开始：

  • Node2D ：适合 2D 游戏
  • Control：适合 UI 界面
  • Node3D：适合 3D 游戏

如果你是第一次接触 Godot，建议先从 Node2D 开始。

3. 保存场景 ​

把场景保存为：

  • main.tscn

建议把它放在项目根目录的 scenes 文件夹里，方便管理。

六、运行你的第一个项目 ​

1. 设置主场景 ​

保存场景后，将它设置为主场景。
这样按下运行按钮时，Godot 会直接启动这个场景。

2. 点击运行 ​

点击编辑器右上角的运行按钮，或者按快捷键运行项目。

如果显示如下，请点击: 选择当前

如果一切正常，你就已经成功完成了：

  • 下载
  • 安装
  • 创建项目
  • 创建场景
  • 运行项目

这意味着你的 Godot 环境已经可以正常使用了。

七、常见问题 ​

1. Godot 打不开怎么办？ ​

可以先检查以下几点：

  • 是否下载了正确的 Windows 版本
  • 文件是否被压缩包完整解压
  • 系统是否缺少运行环境
  • 是否误点了 console 版本并误以为程序没反应

2. 为什么项目路径最好不要太复杂？ ​

路径过长、包含特殊符号、空格过多，偶尔会引起一些兼容问题。
新手阶段建议尽量使用简单路径。

3. Godot 需要安装吗？ ​

大多数情况下不需要。
Godot 的 Windows 版本通常是 解压即用。

4. Godot 支持 C# 吗？ ​

支持。
如果你想用 C# 开发，请下载带有 C# 支持的版本。

八、获取帮助 ​

如果你在安装或启动 Godot 时遇到问题，可以通过以下方式获取帮助：

  • QQ 群：289132257
  • GitHub Issues：https://github.com/licheng1013/licheng1013.github.io/issues

如果你愿意，也可以直接把问题截图发出来，通常更容易定位。

九、下一步学什么 ​

完成安装后，建议继续学习：

  • Godot 编辑器界面介绍
  • 节点和场景是什么
  • GDScript 基础语法
  • 第一个 2D 小游戏
  • 输入、碰撞、动画和 UI

总结 ​

Godot 4 的安装并不复杂，Windows 用户一般只要做到这几步就够了：

  1. 下载官方版本
  2. 解压压缩包
  3. 运行主程序
  4. 创建项目
  5. 新建场景并运行

如果你是刚接触 Godot，先把这一步走通，比直接学复杂功能更重要。
